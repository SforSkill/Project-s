# Signaler une vulnérabilité

Ne pas ouvrir d'issue publique. Utiliser **Security → Report a vulnerability** sur le dépôt GitHub (avis de sécurité privé).

Frontières de sécurité de l'écosystème : [SECURITY_BOUNDARIES](https://github.com/SforSkill/Project-s-docs/blob/main/SECURITY_BOUNDARIES.md). Modèle de menace du jeu (chiffrement, autorité du serveur, limites) : [Project-s-server `docs/security.md`](https://github.com/SforSkill/Project-s-server/blob/main/docs/security.md).
